# Deployment Guide — Sungmin Kim Portfolio

## Quick Start (local development)

```bash
cd portfolio-site
npm install
npm run dev
# Open http://localhost:3000
```

## Deploy to Vercel (recommended)

### Option A — Vercel CLI

```bash
npm install -g vercel
cd portfolio-site
vercel --prod
```

### Option B — GitHub Integration

1. Push this repository to GitHub.
2. Go to https://vercel.com/new and import the repository.
3. If the whole monorepo is pushed, set **Root Directory** to `portfolio-site`.
4. Vercel auto-detects Next.js — click **Deploy**.

### Environment variables on Vercel

In the Vercel dashboard → Project Settings → Environment Variables:

| Variable                | Description                                     |
|-------------------------|-------------------------------------------------|
| `NEXT_PUBLIC_SITE_URL`  | Live domain, e.g. `https://sungminkim.dev`      |
| `RESEND_API_KEY`        | (Optional) API key for contact form emails      |

## Deploy to Netlify

```bash
npm install -g netlify-cli
cd portfolio-site
npm run build
netlify deploy --dir .next --prod
```

Add `netlify.toml` in `portfolio-site/`:

```toml
[build]
  command   = "npm run build"
  publish   = ".next"

[[plugins]]
  package = "@netlify/plugin-nextjs"
```

## Custom Domain

1. Purchase a domain (e.g. `sungminkim.dev`).
2. In Vercel → Project → Domains, add your domain.
3. Update DNS records as instructed by Vercel.

## Contact Form Setup

The contact form hits `POST /api/contact`. To actually send emails:

1. Create an account at https://resend.com (generous free tier).
2. Verify your sending domain.
3. Set `RESEND_API_KEY` in your environment.
4. Uncomment the Resend block in `app/api/contact/route.ts`.
